# Transition

When I started this homelab, my goal was to build a solid foundation in Linux system administration rather than simply install as many services as possible. Every project up to this point was chosen to teach a specific skill, whether it was managing users and permissions, working with Git, writing Bash scripts, automating tasks with Cron, or creating and validating backups.

As the project has grown, I've reached a point where adding more isolated exercises would provide diminishing returns. Instead of creating new sessions just for the sake of documenting another Linux feature, I want the server to evolve into something that I actively use and maintain.

The next stage of this homelab will focus on deploying services that solve real problems for me while continuing to expand my Linux knowledge. Rather than following structured exercises, I'll be learning through installation, configuration, troubleshooting, updates, backups, monitoring, and long-term maintenance.

Some of the projects I'm planning to work on include Pi hole for network wide DNS filtering, Immich or another self-hosted storage solution, a locally hosted AI using Ollama, and any other services that become useful as my homelab grows.
